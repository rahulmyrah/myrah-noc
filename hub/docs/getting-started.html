🚀 Getting Started

From a fresh VPS to a fully running NOC Hub in under 30 minutes.

Prerequisites

  • VPS with Docker + Docker Compose installed (Ubuntu 22.04 recommended)
  • Domain name with DNS A records pointing to your VPS IP
  • Traefik running on the VPS (handles HTTPS automatically)
  • Ports 80 and 443 open in VPS firewall
  • OpenAI API key (for AI assistant)

Step 1: Clone the repo on the VPS

git clone https://github.com/your-org/myrah-noc /opt/myrah-noc
cd /opt/myrah-noc

Step 2: Create .env

cp .env.example .env
nano .env
# Set VPS_DOMAIN, OPENAI_API_KEY, and optionally Azure credentials

Step 3: Start the stack

docker compose up -d

This starts: Prometheus, Alertmanager, Uptime Kuma, Healthchecks, Blackbox Exporter, Grafana, NOC Hub, and Hub API.

Step 4: Configure Uptime Kuma

  1. Open https://status.YOUR_DOMAIN
  2. Create admin account (first visit only)
  3. Add first monitor — see Monitors guide
  4. Set up notification channel — see Alerts guide

Step 5: Customise branding

Edit hub/client.config.json with the client's brand name, logo URL, and accent colour:

docker compose build noc-hub && docker compose up -d noc-hub

Step 6: Smoke-test

# Hub responds
curl -o /dev/null -s -w '%{http_code}' https://noc.YOUR_DOMAIN
# Expected: 200

# AI assistant responds
curl -X POST https://noc.YOUR_DOMAIN/api/chat \
  -H "Content-Type: application/json" \
  -d '{"messages":[{"role":"user","content":"hello"}]}'
# Expected: {"reply":"..."}
