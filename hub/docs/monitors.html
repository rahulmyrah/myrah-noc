📡 Creating & Managing Monitors

Monitors are the core of Uptime Kuma. Each monitor checks a service at a defined interval and alerts if it fails.

How to Create a Monitor

  1. Open Uptime Kuma via the Configure Alerts button on the NOC Hub.
  2. Click + Add New Monitor (top right).
  3. Choose a Monitor Type (see below).
  4. Fill in required fields, add Tags, assign a Notification.
  5. Click Save.

Monitor Types

HTTP(s) — Most Common

Checks a URL returns the expected HTTP status code. Use for websites, APIs, health endpoints.

  • URL: Full URL including https://
  • Expected Status: 200 (default). Use 200-299 for any success.
  • Keyword: Optional — alert if response body does NOT contain this string.

TCP Port

Checks a TCP port accepts connections. Use for databases (5432, 3306, 1433), SMTP (587), Redis (6379).

SSL Certificate

Monitors SSL cert expiry. Alerts N days before expiry (configurable, default 7 days).

Ping (ICMP)

Checks if a server responds to ping. Use for VMs and network devices with no HTTP endpoint.

DNS

Checks that a hostname resolves to the expected IP. Useful for detecting DNS misconfiguration.

Push

Your server calls a unique URL to say "I'm alive". Alert if Uptime Kuma doesn't receive a push within the interval. Use for cron jobs and scheduled tasks.

curl -fsS "https://status.aitoolsfactory.com/api/push/XXXXXXXXXX?status=up&msg=OK"

Recommended Settings

  • Heartbeat Interval: 60s (30s for critical services)
  • Retries: 3 (avoids false alarms)
  • Retry Interval: 20s
  • Resend Notification: Every 1h for sustained outages

Tagging for NOC Hub Sections

Tags determine which section a monitor appears in on the NOC Hub dashboard. Add tags matching the monitorTags in client.config.json:

  • Compute & Containers: compute, aks, vm, app-service, functions
  • Data & Storage: data, database, storage, redis, cosmos, sql
  • AI & Messaging: ai, messaging, events, service-bus
  • Network & Security: network, security, vpn, firewall, keyvault
💡 Tags are case-insensitive. A monitor can have multiple tags and appear in multiple sections.
⚠️ Monitors without matching tags won't appear in NOC Hub sections. Always add at least one tag per monitor.
