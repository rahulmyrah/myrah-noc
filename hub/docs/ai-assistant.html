🤖 AI Assistant

The NOC Assistant (🤖 button, bottom right) is powered by OpenAI GPT-4o-mini and knows this platform end-to-end.

What It Can Help With

  • Step-by-step instructions for configuring monitors and alert channels
  • Explaining what a specific monitor type does
  • Answering questions about the platform architecture
  • Helping you plan your service sections and tagging strategy
  • Explaining how to set up Azure integration
  • Pointing you to the right documentation page

Example Prompts

  • "How do I create a monitor for my Azure App Service?"
  • "Set up Teams notifications for when any service goes down"
  • "How do I add SMS alerts via Twilio?"
  • "What's the difference between HTTP and Push monitors?"
  • "How do I group my services into sections?"
  • "Show me how to connect my Azure subscription"

Limitations

  • Cannot create monitors or make changes — it guides you through steps.
  • Cannot see live data from Uptime Kuma or Prometheus.
  • Conversation history resets when you close the browser tab.

Configuration

Requires an OpenAI API key in .env:

OPENAI_API_KEY=sk-proj-xxxxxxxxxxxxxxxxxxxxxxxx

To hide the assistant for a specific client, set in client.config.json:

"features": { "showAiAssistant": false }

Model: gpt-4o-mini — cost-effective, fast, ~$0.001 per conversation.
