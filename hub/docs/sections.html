🗂️ Service Sections

The NOC Hub groups monitors into sections displayed as cards. Sections are fully configurable via client.config.json.

How Sections Work

Each section has a monitorTags array. Any Uptime Kuma monitor tagged with one of these tags appears in that section. The section card colour reflects the worst monitor status (green/amber/red).

Default Sections

"sections": [
  { "id": "compute",  "label": "Compute & Containers", "icon": "☁️",
    "monitorTags": ["compute","aks","vm","app-service","functions"] },
  { "id": "data",     "label": "Data & Storage",       "icon": "🗄️",
    "monitorTags": ["data","database","storage","redis","cosmos","sql"] },
  { "id": "ai",       "label": "AI & Messaging",       "icon": "🤖",
    "monitorTags": ["ai","messaging","events","service-bus","event-hub"] },
  { "id": "network",  "label": "Network & Security",   "icon": "🌐",
    "monitorTags": ["network","security","vpn","expressroute","firewall","keyvault"] }
]

Adding a Custom Section

Edit hub/client.config.json → add entry to sections array:

{ "id": "pos", "label": "Point of Sale", "icon": "🛒",
  "monitorTags": ["pos","payments","checkout"] }

Rebuild: docker compose build noc-hub && docker compose up -d noc-hub

Tagging a Monitor in Uptime Kuma

  1. Open monitor → Edit.
  2. In Tags field, type tag name → press Enter.
  3. Add all relevant tags (a monitor can appear in multiple sections).
  4. Save. NOC Hub reflects the change within 30 seconds.
💡 For a retail client, try sections: "Customer Website", "POS Systems", "Payments", "Warehouse", "Back Office".
