🔔 Alert Channels Setup

Uptime Kuma supports 60+ notification channels. Here are the most common for business use.

Microsoft Teams

  1. Open the Teams channel → click ... → Connectors → Incoming Webhook → Add.
  2. Give it a name (e.g. "Myrah NOC Alerts") → Create. Copy the webhook URL.
  3. In Uptime Kuma: Settings → Notifications → Add Notification → Microsoft Teams.
  4. Paste URL → Test → Save.

Slack

  1. Go to api.slack.com/apps → Create New App → From Scratch.
  2. Incoming Webhooks → toggle On → Add Webhook to Workspace → choose channel → Allow.
  3. Copy webhook URL.
  4. In Uptime Kuma: Settings → Notifications → Slack → paste URL → Test → Save.

Email (SMTP)

  1. In Uptime Kuma: Settings → Notifications → Email (SMTP).
  2. Fill in SMTP settings:
    • Gmail: Host smtp.gmail.com, Port 587, TLS, use App Password (not your main password)
    • Office 365: Host smtp.office365.com, Port 587
  3. Set To email → Test → Save.

SMS via Twilio

  1. Create account at twilio.com → get a phone number with SMS.
  2. Find Account SID and Auth Token on the Twilio Console dashboard.
  3. In Uptime Kuma: Settings → Notifications → Twilio.
  4. Enter Account SID, Auth Token, From number, To number → Test → Save.

WhatsApp via Twilio

  1. Enable WhatsApp in Twilio Console (requires approval).
  2. Use the same Twilio notification type — prefix numbers with whatsapp:.
  3. Example To: whatsapp:+447XXXXXXXXX

Telegram

  1. Message @BotFather on Telegram → /newbot → get Bot Token.
  2. Start a chat with your bot → get Chat ID from https://api.telegram.org/botTOKEN/getUpdates.
  3. In Uptime Kuma: Telegram → enter Bot Token + Chat ID → Test → Save.
💡 Best practice: create a "Critical" notification (Teams + SMS) and a "Warning" notification (email only). Assign based on monitor criticality.
